# Investigative Biology Portfolio

> [!intro] Experimental design and data analysis — the capstone research strand.

## Experimental design

A good biology experiment controls variables, includes replicates and a control group, and defines what is measured — the basis of trustworthy results.

## Data analysis

Biological data is variable, so statistics (means, spread, significance) separate real effects from noise — reusing the maths statistics strand.

```formula Key facts
Control one variable; include a control group; replicate
Use statistics to test if a difference is real
Correlation ≠ causation
```

> [!example] **Worked example**
> **Problem.** You find plant height correlates with soil nitrogen. Can you conclude nitrogen causes taller plants?
> >
> > **Solution.** Not from correlation alone — run a controlled experiment varying only nitrogen to test causation.
