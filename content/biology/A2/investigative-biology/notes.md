# Investigative Biology Portfolio

> Experimental design and data analysis — the capstone research strand.

## Experimental design

A good biology experiment controls variables, includes replicates and a control group, and defines what is measured — the basis of trustworthy results.

## Data analysis

Biological data is variable, so statistics (means, spread, significance) separate real effects from noise — reusing the maths statistics strand.

## What you should be able to do

- Design controlled experiments
- Analyse biological data
- Draw evidence-based conclusions
