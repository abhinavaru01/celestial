# Tricks & Problem-Solving Techniques — Linear Relationships & the Coordinate Plane

> Faster, cleaner ways to handle this topic.

- Slope = (change in y)/(change in x) between any two points on the line.

- A steeper line means a bigger rate; a flat line means y does not change.

- Set x = 0 for the y-intercept, y = 0 for the x-intercept.
