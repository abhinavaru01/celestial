# Functions as Objects

> [!intro] Function notation, domain and range, composition, inverses and transformations of graphs.

## A function is a machine

A function f takes an input and returns exactly one output, written f(x). Domain is the allowed inputs, range the possible outputs. Thinking of functions as objects you can combine is a big conceptual step.

## Composition and inverses

Composition f(g(x)) feeds one function's output into another. The inverse f⁻¹ undoes f. Graph transformations (shifts, stretches, reflections) change a function predictably.

```formula Key formulas
f: one input → exactly one output
Composition: (f∘g)(x) = f(g(x))
Inverse: swap x and y, solve for y
Vertical-line test checks if a graph is a function
```

> [!example] **Worked example**
> **Problem.** If f(x) = 2x + 1 and g(x) = x², find f(g(3)).
> >
> > **Solution.** g(3) = 9, then f(9) = 2(9) + 1 = 19.

## What you should be able to do

- Use function notation and find domain/range
- Compose and invert functions
- Transform graphs (shift, stretch, reflect)
