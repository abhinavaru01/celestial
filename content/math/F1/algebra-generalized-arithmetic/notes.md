# Algebra as Generalized Arithmetic

> Variables are just numbers whose value we have not fixed yet; algebra is arithmetic with letters standing in for numbers.

## A variable is a placeholder

A letter like x simply holds a number we do not yet know. Every rule of arithmetic still applies — algebra generalizes it so one statement covers all numbers at once.

## Like terms and the distributive law

Only terms with the same variable part combine: 3x + 2x = 5x, but 3x + 2 stays as is. The distributive law a(b + c) = ab + ac is the engine for expanding and factoring.

## What you should be able to do

- Write and evaluate algebraic expressions
- Collect like terms and use the distributive law
- Translate word statements into expressions
