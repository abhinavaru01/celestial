# The Periodic Table as a Map

> Periods and groups as patterns, not a list — organising elements by structure and properties.

## A map, not a list

Elements are arranged by increasing atomic number into periods (rows) and groups (columns). Elements in the same group have similar properties because they share outer-electron counts.

## Trends

Properties change predictably: reactivity, size and metallic character trend across periods and down groups. The table lets you predict, not memorise.

## What you should be able to do

- Read the periodic table's layout
- Relate group to properties
- Predict trends across periods and groups
