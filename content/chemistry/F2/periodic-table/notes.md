# The Periodic Table as a Map

> [!intro] Periods and groups as patterns arising from electron configuration — a predictive map, not a list to memorise.

## A map from electron structure

Elements are ordered by increasing atomic number into periods (rows) and groups (columns). Group number equals the number of outer (valence) electrons, which is why a group shares chemistry.

## Trends are predictable

Reactivity, atomic size and metallic character change smoothly across periods and down groups — Group 1 metals get more reactive down the group; Group 17 non-metals less reactive down.

```formula Key formulas
Group number (main groups) = number of valence electrons
Period number = number of occupied electron shells
```

> [!example] **Worked example**
> **Problem.** Element in Group 2, Period 3. How many valence electrons and shells, and what is it?
> >
> > **Solution.** 2 valence electrons and 3 shells → magnesium (Mg). Its 2 outer electrons make it a reactive Group-2 metal forming Mg²⁺.

## What you should be able to do

- Read the periodic table's layout
- Relate group number to valence electrons
- Predict reactivity trends
