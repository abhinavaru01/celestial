# Functional-Group Chemistry

> Alcohols, aldehydes, ketones, carboxylic acids and amines — reactions by group.

## Groups define reactivity

Each functional group has characteristic reactions: alcohols oxidise, acids neutralise bases, amines act as weak bases. Knowing the group predicts the chemistry.

## Interconversion

Functional groups convert into one another along known routes (e.g., alcohol → aldehyde → acid by oxidation), letting chemists build target molecules.

## What you should be able to do

- Recognise major functional groups
- Predict characteristic reactions
- Interconvert functional groups
