# Chemical Thermodynamics

> [!intro] Enthalpy, entropy and Gibbs free energy — the thermodynamic criterion for whether a reaction is spontaneous.

## Enthalpy and entropy

Enthalpy (ΔH) tracks heat exchanged; entropy (ΔS) tracks disorder. Reactions are favoured by releasing energy (ΔH<0) and increasing disorder (ΔS>0).

## Gibbs free energy

ΔG = ΔH − TΔS decides spontaneity: ΔG < 0 spontaneous, = 0 at equilibrium, > 0 non-spontaneous. The T term means some reactions become spontaneous only above/below a certain temperature.

```formula Key formulas
ΔG = ΔH − TΔS  (T in kelvin)
ΔG < 0 spontaneous; = 0 equilibrium; > 0 non-spontaneous
ΔG° = −RT ln K
```

> [!example] **Worked example**
> **Problem.** A reaction has ΔH = +40 kJ/mol and ΔS = +0.100 kJ/(mol·K). Above what temperature is it spontaneous?
> >
> > **Solution.** Spontaneous when ΔH − TΔS < 0 → T > ΔH/ΔS = 40/0.100 = 400 K. So spontaneous above 400 K.

## What you should be able to do

- Use enthalpy and entropy changes
- Apply ΔG = ΔH − TΔS
- Predict spontaneity and its temperature dependence
