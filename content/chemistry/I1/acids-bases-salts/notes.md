# Acids, Bases & Salts

> The pH scale, neutralisation, and an introduction to titration.

## Acids and bases

Acids release H⁺ ions, bases release OH⁻ (or accept H⁺). The pH scale (0–14) measures acidity; 7 is neutral.

## Neutralisation

Acid + base → salt + water. Titration uses this to find an unknown concentration by adding a known solution until neutral.

## What you should be able to do

- Describe acids and bases
- Use the pH scale
- Explain neutralisation and titration
