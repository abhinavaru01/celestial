# Acids, Bases & Salts

> [!intro] The pH scale as a logarithm of H⁺ concentration, neutralisation, and titration.

## Acids, bases and pH

Acids donate H⁺ (Brønsted); bases accept H⁺ (or donate OH⁻). pH = −log[H⁺] compresses a huge range into 0–14; each unit is a ten-fold change in acidity.

## Neutralisation and titration

Acid + base → salt + water. Titration finds an unknown concentration by adding a standard solution to the equivalence point, using n = CV.

```formula Key formulas
pH = −log[H⁺],  [H⁺] = 10^(−pH)
At 25°C: [H⁺][OH⁻] = 1.0×10^(−14)
Acid + base → salt + water
Titration: n = C × V
```

> [!example] **Worked example**
> **Problem.** A solution has [H⁺] = 1×10⁻³ mol/L. Find its pH and state if it is acidic.
> >
> > **Solution.** pH = −log(10⁻³) = 3. Since pH < 7, the solution is acidic.
