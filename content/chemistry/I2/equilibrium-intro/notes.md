# Quantitative Equilibrium (Introduction)

> Reversible reactions, dynamic equilibrium, and Le Chatelier's principle.

## Dynamic equilibrium

Reversible reactions reach a state where forward and backward rates are equal — concentrations stay constant though reactions continue. Nothing has stopped; it is balanced.

## Le Chatelier

If you disturb an equilibrium (concentration, temperature, pressure), it shifts to oppose the change. This predicts how to push a reaction toward products.

## What you should be able to do

- Explain dynamic equilibrium
- Apply Le Chatelier's principle
- Predict shifts from changes
