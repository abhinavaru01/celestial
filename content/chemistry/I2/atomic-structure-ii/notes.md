# Atomic Structure II

> Electron configuration and quantum shells, treated intuitively.

## Electrons in shells

Electrons occupy energy levels (shells and subshells). Filling them in order of energy explains the periodic table's shape and each element's chemistry.

## Configuration predicts chemistry

The outer-shell configuration determines how an element bonds. Elements in the same group share outer configurations — hence similar behaviour.

## What you should be able to do

- Write electron configurations
- Relate configuration to the periodic table
- Explain energy levels intuitively
