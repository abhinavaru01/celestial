# Project 1

> [!intro] Build a complete small program (e.g., a quiz game), committed to git.

## Putting it together

Your first complete program combines everything so far: input, variables, conditionals, loops and functions — decomposed into parts and assembled.

## Ship it

A finished, committed project (a quiz game, a text tool) is proof you can build, not just follow tutorials. Commit as you go.

```formula Key syntax & rules
Build one small feature at a time and test it
Reuse functions to avoid repetition
Commit each working step
```

> [!example] **Worked example**
> **Problem.** What is a reliable way to build a first quiz-game project?
> >
> > **Solution.** Write and test one question flow, wrap it in a function, then loop it for more questions — committing at each working stage.

## What you should be able to do

- Combine variables, loops, functions
- Build a working program
- Version-control the project
