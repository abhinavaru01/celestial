# Project 1

> Build a complete small program (e.g., a quiz game), committed to git.

## Putting it together

Your first complete program combines everything so far: input, variables, conditionals, loops and functions — decomposed into parts and assembled.

## Ship it

A finished, committed project (a quiz game, a text tool) is proof you can build, not just follow tutorials. Commit as you go.

## What you should be able to do

- Combine variables, loops, functions
- Build a working program
- Version-control the project
