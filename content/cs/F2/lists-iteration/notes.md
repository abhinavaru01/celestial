# Lists & Iteration

> [!intro] The list — the first data structure — with indexing, mutation and traversal.

## Storing many values

A list holds an ordered collection. Indexing (starting at 0) accesses elements; lists are mutable, so you can change, add and remove items.

## Traversal

Looping over a list processes each element in turn — the pattern behind searching, summing and transforming collections.

```formula Key syntax & rules
Index starts at 0; last is len−1
append() adds; pop()/remove() delete
for item in list: traverses
```

> [!example] **Worked example**
> **Problem.** For a = [10, 20, 30], what is a[0] + a[-1]?
> >
> > **Solution.** a[0] = 10 (first), a[-1] = 30 (last) → 10 + 30 = 40.

## What you should be able to do

- Create and index lists
- Add, remove and change elements
- Iterate over a list
