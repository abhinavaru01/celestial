# Lists & Iteration

> The list — the first data structure — with indexing, mutation and traversal.

## Storing many values

A list holds an ordered collection. Indexing (starting at 0) accesses elements; lists are mutable, so you can change, add and remove items.

## Traversal

Looping over a list processes each element in turn — the pattern behind searching, summing and transforming collections.

## What you should be able to do

- Create and index lists
- Add, remove and change elements
- Iterate over a list
