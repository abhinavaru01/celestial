# Software Design

> Requirements, decomposition, data modelling and interfaces.

## Design before code

Real software starts with understanding requirements, then decomposing the system into components with clear responsibilities and interfaces.

## Data modelling

Deciding how data is structured and how components talk (interfaces) shapes everything. Good design makes code easier to build, test and change.

## What you should be able to do

- Gather requirements
- Decompose a system
- Design data models and interfaces
