# Capstone Project

> [!intro] An independently designed, built, tested and version-controlled software project — the graduation bar.

## The graduation project

The capstone is a real, useful piece of software you design, build, test and document yourself — the direct proof of the program's goal: you can build, not just pass tests.

## End to end

It brings together design, data, code, testing, git and a clear README. Presenting it demonstrates genuine, independent capability.

```formula Key syntax & rules
Design → build → test → document → ship
Scope small enough to finish and polish
Version-control throughout; write a clear README
```

> [!example] **Worked example**
> **Problem.** Why scope a capstone project small?
> >
> > **Solution.** A small, finished, tested and documented project demonstrates real ability far better than an ambitious unfinished one.

## What you should be able to do

- Design and build a real project
- Test and document it
- Version-control and present it
