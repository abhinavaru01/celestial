# Working with a Codebase

> Reading unfamiliar code, git collaboration workflows, and code review.

## Reading code

Most professional work is reading and modifying existing code, not writing from scratch. Skimming structure, following functions, and running it build understanding.

## Collaboration

Teams use branches, pull requests and code review to change code safely. Review catches bugs and shares knowledge — a social skill as much as technical.

## What you should be able to do

- Read and navigate unfamiliar code
- Use branch-based collaboration
- Give and receive code review
