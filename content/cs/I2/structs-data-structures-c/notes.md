# Structs & Building Data Structures in C

> [!intro] Grouping data with structs, and re-implementing a linked list with pointers.

## Structs group data

A struct bundles related fields under one type (like a record). Combined with pointers, structs build complex data structures from scratch.

## Linked lists in C

Re-implementing a linked list with structs and pointers shows how the abstract structure works at the memory level — the payoff of learning C.

```formula Key syntax & rules
struct groups related fields into one type
Linked-list node = data + pointer to next
Keep the head pointer to not lose the list
```

> [!example] **Worked example**
> **Problem.** What two things does a linked-list node hold?
> >
> > **Solution.** The data value, and a pointer to the next node (NULL at the end).

- Build a linked list in C
- Connect structs and pointers
