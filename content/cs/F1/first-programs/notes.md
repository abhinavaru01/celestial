# First Programs

> Running Python, printing output, comments, and the edit-run loop.

## Your first output

print() displays text on screen. Writing, running and seeing the result is the fundamental loop of programming — the fastest way to learn is to run code often.

## Comments

Comments (# in Python) are notes for humans, ignored by the computer. They explain why code does something, aiding the next reader.

## What you should be able to do

- Run a Python program
- Use print and comments
- Understand the edit-run cycle
