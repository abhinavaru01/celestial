# Booleans & Conditionals

> if/elif/else and boolean logic — making programs decide.

## Making decisions

Conditionals run different code depending on whether a condition is True or False. if/elif/else lets a program choose a path — the basis of all logic.

## Boolean logic

Conditions combine with and, or, not. Understanding truth values (from maths logic) lets you express complex decisions correctly.

## What you should be able to do

- Use if/elif/else
- Combine conditions with and/or/not
- Trace which branch runs
